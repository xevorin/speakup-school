# Speak Up: лендинг онлайн-школы английского

Учебный проект для портфолио. Школа «Speak Up» вымышленная, цены и преподаватели придуманы. Заказчика нет.

Сайт: https://xevorin.github.io/speakup-school/

![Скриншот лендинга](screenshot.png)

## Что есть на странице

- Первый экран с оффером «Заговорите по-английски за 3 месяца» и кнопкой записи на пробный урок.
- Блок «Как проходят уроки»: пробный урок, программа под цель, Zoom 2 раза в неделю, отчёт о прогрессе.
- Тест из 4 вопросов с полосой прогресса и кнопкой «Назад». В конце показывает уровень (A1–B2) и формат: индивидуально, в паре или в группе. Кнопка под результатом подставляет их в форму заявки.
- Три тарифа: индивидуально от 1 400 ₽, в паре от 990 ₽, группа до 5 человек от 650 ₽ за урок. Переключатель «8 / 16 уроков» пересчитывает сумму пакета, на 16 уроков скидка 10%.
- Три преподавателя, аватары нарисованы в SVG.
- Шесть частых вопросов в аккордеоне (кнопки с `aria-expanded`).
- Форма заявки: имя, телефон или Telegram, удобное время, согласие на обработку данных. Поля проверяются, после отправки показывается экран «Заявка принята». Форма демонстрационная и ничего не отправляет.

Вёрстка работает от 360 px без горизонтальной прокрутки. Фокус с клавиатуры виден, при `prefers-reduced-motion` анимации отключаются.

## Стек

HTML, CSS и JavaScript без фреймворков и сборки. Шрифт Nunito из Google Fonts.

- `js/quiz.js` — вопросы теста и функция `scoreQuiz(answers)`, которая считает уровень и формат.
- `js/pricing.js` — расчёт пакетов `calcPackage()` и проверка формы `validateLead()`.
- `js/main.js` — работа с DOM: тест, переключатель цен, аккордеон, форма.

Функции в `quiz.js` и `pricing.js` не трогают DOM, поэтому их можно проверить в Node:

```
node tests/logic.test.js
```

## Как открыть

Скачайте папку и откройте `index.html` в браузере. Сервер не нужен, все пути относительные.
